# RetailEase Pro

Create a web application called RetailEase: A Smart Credit and Inventory Assistant for Local Grocery Stores.

This is a college project prototype for a small local grocery/kirana shop owner.

For now, focus ONLY on creating a polished and professional UI and basic application structure. Do not over-engineer the project.

Create these pages/routes:

Login

Dashboard

Customers

Products

Inventory

Sales

Udhar / Credit

Payments

Reports

Design requirements:

Modern, clean business dashboard

Professional UI suitable for a college project demonstration

Responsive design for desktop and laptop screens

Use a consistent sidebar navigation

Use cards, tables, badges, dialogs/modals and forms where appropriate

Use a clean light theme

Use meaningful icons

Make the interface look like a real grocery-store management application

Use the project name "RetailEase" throughout the UI

Do not add home delivery, e-commerce, payment gateway, SMS, WhatsApp or unnecessary features

Do not use fake AI features

Do not create excessive animations

Use realistic placeholder/demo data only where necessary to make the UI visually understandable.

At this stage, do NOT implement complex database functionality.

After creating the UI, make sure all navigation links work and every page can be opened without errors.
